OFFLINE USAGE INSTRUCTIONS
--------------------------

✅ METHOD 1: Direct File Open (Easiest)
1. Copy this entire folder to a USB drive
2. Plug USB into your Android TV or PC
3. Open "TV Bro" browser (install from Play Store if needed)
4. Navigate to: USB Drive → bingo-offline → index.html
5. Play! No internet required.

✅ METHOD 2: PWA Installation (Better Experience)
1. Open index.html in Chrome browser (on PC or phone)
2. Look for the "Install" icon (⬇️) in address bar
3. Click "Install Bingo Zone 6"
4. App launches fullscreen, works completely offline
5. Find icon on your home screen for quick access

✅ METHOD 3: Local Network (For Multiple Devices)
1. On PC: Open terminal in this folder
2. Run: python -m http.server 8000
3. On TV/Phone: Open browser to http://YOUR_PC_IP:8000
4. Game loads and caches for offline use

🎮 CONTROLS (TV Remote / Keyboard)
----------------------------------
• OK / Enter     → Call next number
• Arrow Keys     → Navigate number grid
• Back / Escape  → Exit fullscreen mode
• F Key          → Toggle fullscreen
• M Key          → Mute/unmute sound
• R Key          → Reset game
• Space          → Start/stop auto-call

🔊 AUDIO NOTES

⚙️ TROUBLESHOOTING
------------------
❓ Game won't load on TV?
→ Use "TV Bro" browser instead of stock browser
→ Copy files to internal storage, not just USB

❓ No sound?
→ Click/tap anywhere on screen once to unlock audio
→ Check device volume settings
→ Toggle sound button to reset

❓ Voice not speaking?
→ System voices may need internet to download initially
→ Visual display still works perfectly offline

❓ PWA won't install?
→ Must be served via HTTPS or localhost (not file://)
→ Use Method 3 (local server) for installation
